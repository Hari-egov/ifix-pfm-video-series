# iFIX · Reimagining PFM in India — the blue book in six short videos

Six narrated, animated, English-subtitled videos, one per part of eGov Foundation's blue book
*Reimagining PFM in India: Strategy & Approach* (2023): executive summary, PFM in India, the challenges and
the pivotal problem, standardised fiscal events and the iFIX platform, what iFIX enables, and how to operationalise it.

**Watch:** open `index.html` (published with GitHub Pages). One player, part tabs, steps and a transcript that
follow the narration, downloads, and links that open a part at a given second (for example `#V04&t=91`).

Narration is a synthetic voice; the videos are generated from text storyboards, so wording can be corrected and
re-rendered quickly. Source: eGov Foundation, www.egov.org.in.
